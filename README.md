# Book Finder App

A simple frontend-only web app to search for books using the **Open Library API**. Users can search by title and view details such as the cover image, author(s), and first published year.

## Live Demo

🔗 [Try the Live App](https://sparkly-cheesecake-b1ce57.netlify.app/)

## Tech Used

- **HTML**
- **CSS / Bootstrap 5**
- **JavaScript (Vanilla)**
- **Open Library API**

## Features

- 🔍 Search books by title  
- 🖼️ Display cover image, title, authors, and published year  
- 📱 Mobile responsive using Bootstrap 5  
- 💻 100% frontend — no backend needed

## 🧠 How It Works

1. User enters a book title.
2. The app sends a request to the **Open Library Search API**.
3. It displays a list of matching books with their covers, authors, and publishing info.
